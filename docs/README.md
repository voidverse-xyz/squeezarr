# Squeezarr documentation

Project documentation is grouped by purpose:

- **[Architecture](architecture/architecture.md)** — system design, process model, storage,
  queue, runners, and deployment.
- **[Development conventions](development/squeezarr-conventions.md)** — repository structure,
  coding conventions, and verification commands.
- **[Assets](assets/)** — logos and screenshots used by the project documentation.

The root [README](../README.md) contains installation and usage instructions. The root
[AGENTS.md](../AGENTS.md) is the authoritative source for automated contributor instructions.
